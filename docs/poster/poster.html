Background

The Challenge

The NCCR Data Platform holds linked cancer data across 9 datasources for 1.4M patients — but researchers face barriers discovering what's available before committing to an IRB-approved data request.

The Gap

  • 533 variables across registry, claims, pharmacy, and radiation oncology data
  • Metadata locked in platform-specific JSON formats
  • No machine-readable catalog for external discovery
  • New researchers lack tools to explore without an account

Our Solution

Publish NCCR metadata as linked data using standard RDF vocabularies, making it queryable by both humans (via tools) and AI systems (via structured knowledge).

Key insight: The metadata itself becomes the discovery tool — no patient data access needed.

AI-Assisted Discovery

LLM + Structured Metadata

An AI assistant reads the published metadata and provides grounded, factual answers about NCCR data — without accessing patient records.

I want to study treatment for brain tumors in children under 15. What data does NCCR have?
Based on the NCCR metadata:

Registry (CTC): 164,378 CNS tumor records with diagnosis, staging, summary treatment, and survival.

Radiation Oncology (RO): Detailed treatment — proton therapy (1,232 records), 3D conformal (1,367), with dose, fractions, and timing.

Pharmacy (PHARM): Temozolomide (46,567 dispensing records), dexamethasone (76,640 records).

Want me to build a cohort definition for CTC + RO + PHARM, ages 0-14, ICCC code 03?

Why This Works

  • Structured — RDF triples queryable via SPARQL
  • Complete — all variables, values, and frequencies
  • Grounded — LLM answers backed by real metadata, not hallucination
  • Public — no authentication needed

Portable Cohort Definitions

@prefix nccr: <...vocab#> .

<urn:nccr:cohort:abc> a nccr:CohortDefinition ;
  nccr:cohortName "AYA Leukemia" ;
  nccr:includesSource nccr-ds:ctc, nccr-ds:pharm ;
  nccr:hasFilterCriterion [
    nccr:appliesFilter nccr-flt:MinAge ;
    nccr:filterNumericValue 15 ] .

Impact & Future

Current Impact

  • FAIR compliance — Findable, Accessible, Interoperable, Reusable
  • NLM Dataset Catalog — 9 datasets ready for ingestion
  • Education — 12 curriculum exercises for training researchers
  • Reproducibility — Cohort definitions as portable artifacts

Future Directions

  • Deploy AI discovery agent with metadata as knowledge base
  • Platform integration — import/export cohorts as RDF
  • Automated CI/CD publishing after each data release
  • Cross-CADR interoperability via shared vocabulary
  • Public SPARQL endpoint
