# DATMM Catalog Files

Individual DATMM records for the NCCR Data Platform, structured per NLM requirements.

| File | Description |
|------|-------------|
| [repository.ttl](repository.ttl) | NCCR Data Platform as a DATMM Repository |
| [agents.ttl](agents.ttl) | Shared agents (NCI, CCDI, SEER, COG, DCCPS) and contributions |
| [concepts.ttl](concepts.ttl) | Subject concepts with identifiers and scheme membership |
| [ctc.ttl](ctc.ttl) | Consolidated Tumor Case dataset |
| [abm.ttl](abm.ttl) | Area-Based Measures dataset |
| [ccdi.ttl](ccdi.ttl) | CCDI Mappings dataset |
| [cog.ttl](cog.ttl) | Children's Oncology Group dataset |
| [mcd.ttl](mcd.ttl) | Medical Claims Diagnosis dataset |
| [mce.ttl](mce.ttl) | Medical Claims Enrollment dataset |
| [mcp.ttl](mcp.ttl) | Medical Claims Procedure dataset |
| [pharm.ttl](pharm.ttl) | Pharmacy Claims dataset |
| [ro.ttl](ro.ttl) | Radiation Oncology dataset |
